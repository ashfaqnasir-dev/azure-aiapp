# 🚀 Unit 1 - Introduction to Microsoft Foundry Agent Service

> **Objective:** Microsoft Foundry Agent Service (jo pehle Azure AI Agent Service kehlata tha) ka introduction aur is module ke learning goals ko samajhna.

---

## 🎯 Module Ka Maqsad (Short Summary)
Farz karein aap ek **Healthcare company** ke liye kaam kar rahe hain. Aapko ek aisa AI Agent banana hai jo patients se baat kare, unki appointments schedule kare, aur medical data access kare (bina security rules tode).

Agar aap yeh sab khud se banayein, toh aapko bohot servers, coding, aur security ki tension leni paregi.

**Iska aasan hal:** **Microsoft Foundry Agent Service** hai. Yeh ek **Fully Managed** platform hai jahan aap bina kisi server ki fikar ke AI Agents bana sakte hain, deploy kar sakte hain, aur scale kar sakte hain.

---

## 💡 Is Module Mein Aap Kya Seekhenge? (Learning Objectives)
- [ ] AI Agents kya hote hain aur unka maqsad kya hai.
- [ ] Microsoft Foundry Agent Service ki khaas features.
- [ ] VS Code mein Foundry Toolkit extension set up karna.
- [ ] AI Agents ko banana aur configure karna.
- [ ] Agents ke andar Tools (jaise API ya functions) add karna.
- [ ] Playgrounds mein agents ko test karna.
- [ ] Agents ko apps ke sath jorna (Integrate karna).
