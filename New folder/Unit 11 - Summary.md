## 📖 Module Recap

Aapne is module mein seekha ke **Microsoft Foundry Agent Service** ke zariye AI Agents kaise banate hain (chahe **Foundry Portal** use karein ya **Visual Studio Code**). 

Yahan kuch ahem baatein hain jo aapne seekhi:
- [ ] **AI Agents:** Yeh kya hain aur automation aur decision-making ke liye kyun zaroori hain.
- [ ] **Agent Types:** 
  - **Declarative Agents:** Jo visual designers aur YAML se configure hote hain.
  - **Hosted Agents:** Jo code ke zariye ban kar deploy hote hain.
- [ ] **Development Approaches:** Portal (no-code) vs VS Code (code-first) kab aur kyun use karna hai.
- [ ] **Instructions & Personality:** Clear instructions likh kar agent ka behaviour set karna.
- [ ] **Extending Capabilities:** Tool Catalog use karke agents mein taqat add karna (Code Interpreter, File Search, Bing Web Search, Azure AI Search, etc.).
- [ ] **Testing, Deploying, Integration:** Playgrounds mein test karna, production mein deploy karna, aur apni apps ke sath integrate karna.
