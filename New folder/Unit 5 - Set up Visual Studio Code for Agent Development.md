# 🛠️ Unit 5 - Set up Visual Studio Code for Agent Development

> **Objective:** Foundry Toolkit extension ke zariye AI agents ko Visual Studio Code mein set up aur configure karna.

Yeh unit batati hai ke **Foundry Toolkit for VS Code** extension ke zariye AI agents ko seedha apne code editor ke andar kaise set up kiya jata hai.

---

## 1. Foundry Toolkit Extension Kya Hai?
Yeh extension VS Code ko ek mukammal Agent development platform bana deta hai. Iske 3 main hissay hain:
- [ ] **Resources:** Yahan models, agents, connections aur vector stores manage hote hain.
- [ ] **Tools:** Yahan Model Catalog, Playgrounds, aur deployment features milte hain.
- [ ] **Help and Feedback:** Support aur documentation ke liye.

---

## 2. Installation Process
- [ ] **Step 1:** VS Code kholein aur Extensions (`Ctrl+Shift+X`) mein jayein.
- [ ] **Step 2:** Search bar mein **`Foundry Toolkit`** likhein.
- [ ] **Step 3:** **Install** par click karein.
- [ ] **Step 4:** Install hone ke baad, left side (Activity Bar) par Foundry Toolkit ka icon nazar aayega.

---

## 3. Azure Account Connect Karna
- [ ] **Step 1:** VS Code ke left side mein **Azure icon** par click karein.
- [ ] **Step 2:** Apne Azure account se **Sign in** karein (agar pehle se nahi hain).
- [ ] **Step 3:** Apni **Subscription** ko expand karein.
- [ ] **Step 4:** **Foundry** section ke andar apne Project par Right-Click karein.
- [ ] **Step 5:** **"Open in Foundry Extension"** select karein.
- [ ] **Step 6:** Ab aap project ke saare resources (agents, models) extension ke andar dekh sakte hain.

---

## 4. Model Deploy Karna (Agar Pehle Se Nahi Hai)
Agents ko chalne ke liye ek AI Model chahiye hota hai.
- [ ] **Step 1:** Extension ke **Resources** section mein jayein.
- [ ] **Step 2:** **Model deployments** ko expand karein aur **`+`** icon par click karein.
- [ ] **Step 3:** Model select karein (jaise `GPT-4o`).
- [ ] **Step 4:** Deployment ka naam aur settings set karein.
- [ ] **Step 5:** **Deploy** par click karein.

---

## 5. VS Code Mein Agents Ke Sath Kaam Karna
- [ ] **Auto Sync:** Jo agents Foundry portal mein bante hain, woh VS Code ke Resources section mein automatically show ho jate hain.
- [ ] **YAML Editing:** Aap VS Code mein agent ki settings (YAML file) change kar sakte hain aur woh direct Foundry mein save ho jati hain.
- [ ] **Multiple Agents Manage Karna:** Aap ek hi jagah se alag alag agents ko browse, compare, duplicate (copy), aur archive kar sakte hain.
